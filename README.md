# LinkVault

Личная веб-библиотека для полезных ссылок. Сохраняйте находки, раскладывайте их по коллекциям, добавляйте теги и заметки, отмечайте избранное и находите всё поиском.

## Возможности

- Добавление, редактирование и удаление ссылок.
- Коллекции и теги с фильтрами.
- Избранное и поиск по названию, адресу и заметке.
- Адаптивный интерфейс для компьютера и телефона.
- Локальное хранение в SQLite, без сторонних PHP-библиотек.
- Проверка URL, экранирование HTML и CSRF-защита форм.

## Требования

- PHP 8.1 или новее.
- Расширение PDO_SQLite.

## Запуск

Откройте терминал в папке проекта и выполните:

```powershell
php -S localhost:8000 router.php
```

Затем откройте <http://localhost:8000>. При первом запуске приложение создаст `storage/linkvault.sqlite` и добавит несколько примеров. Запускайте LinkVault только локально: в приложении нет учётных записей, поэтому не публикуйте его в интернете и не открывайте доступ для недоверенной сети.

Папке проекта нужны права на создание каталога `storage` и запись SQLite-файла. При использовании Apache каталог `storage` закрыт от веб-доступа файлом `.htaccess`; для других веб-серверов настройте аналогичный запрет.

## Данные

Все ссылки хранятся локально в `storage/linkvault.sqlite`. Для резервной копии достаточно скопировать этот файл при остановленном сервере.
